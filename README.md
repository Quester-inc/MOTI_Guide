## 파일 구성

- `index.html`: 공통 페이지, 검색 입력과 목차 영역.
- `app.js`: 주제별 설명·이미지 참조, 단계별 진입·동작·결과, 위치 표시 선택, 검색과 페이지 이동.
- `styles.css`: 기존 사이트 디자인과 단계 목차·본문 링크·긴 기술 용어의 줄바꿈, 화면 이미지의 번호 표시와 설명.
- `guide.html`: 기존 `?page=` 링크를 현재 페이지로 연결하는 호환 진입점.
- `assets/current/`: 현재 제품 UI로 생성한 화면 예시. 기존 `assets/`의 착용·손동작 이미지는 필요한 절차에 유지한다.

## 화면 예시와 후속 교체

2026-10-22 목차·설명 정리에서는 기존 이미지 파일과 이미지 객체 42개 참조를 보존하고, 가입·복구 이미지를 해당 새 문서로 이동했다. 2026-10-23 PC 안내에 열 장면을 추가했을 때는 총 52개 참조였다. 이어 전체 가이드 확장에서는 새 네이티브 화면 48장을 생성해 이미지 배치를 103곳으로 늘렸고, UI 위치 설명을 309개 넣었다. 같은 장면의 저해상도 이미지 참조 12개는 2배 화면으로 교체했으며 원본 PNG 45개와 과거 캡처 기록은 보존했다.

당시 신규 48장은 인증·계정·업데이트·오류 보고 16장, 작업공간·장치·바인딩·보정·뷰 설정 20장, 녹화·보관함·CSV·UDP 12장이다. 특히 보정은 플랫·엄지·시작·프로필 선택·프로필 저장을 추가했고, 문제 해결은 해당 상태를 확인할 화면을 각 증상에 연결했다. 기존 착용·동작 사진과 3D 화면은 역할에 맞춰 유지한다. 2026-10-26에는 새 원본 32장, 이어 실제 앱 조작 결과 8장을 더 추가했다. 파일 보관 수와 문서 내 배치 수는 서로 다르며, `assets/current/manifest.json`에는 원본 보존분을 포함해 133개 화면 이미지가 기록되어 있다.

화면 이미지는 다음 두 방식으로 확보했다. 각 캡션의 예시 상태와 설명을 함께 확인한다.

- 실제 Windows 앱 창 15장: 기존 손 메트릭의 예시 TAKE 재생, 라이브 뷰의 예시 장비, 부착 설정의 3D 조정 핸들, 패널 관리, 텔레오퍼레이션 설정과 로봇 손 갤러리 6장에, 2026-10-26 장갑 미연결·손 메트릭 대기 화면 1장과 부착·표시·시점 조작 결과 8장을 추가했다. 실행 파일의 GPU 렌더링을 포함하며 별도 사용자 데이터 폴더에서 캡처했다.
- 제품 UI 예시: 실제 ImGui 렌더링 코드의 CPU 캡처. 기존 22장, 녹화·파일 관리 7장, PC 관리·사용 전환 10장, 전체 가이드 확장 48장과 2026-10-26 조작·결과 화면 31장이다. 계정·장비·녹화 상태에는 예시 데이터를 사용했다.

PC 안내 10장과 전체 확장 48장은 실제 네이티브 뷰를 예시 상태로 실행하고 한글 글꼴을 2배 밀도로 렌더링했다. 해당 패널·대화상자 영역을 직접 렌더링해 불필요한 바깥 배경을 줄였으며 PNG 원본을 다시 그리거나 표시를 합성하지 않았다. 당시 Windows 앱 제어 연결을 사용할 수 없어 생성한 CPU 화면 예시이며, 실제 OS 창이나 운영 계정의 캡처와 구분한다. 2026-10-26 추가한 CPU 예시 31장도 같은 직접 렌더링 방식을 사용했다.

PC 안내의 초기 25개 표시와 전체 안내에 확장한 위치 표시는 가이드의 HTML/CSS다. 버튼의 ImGui 위치 또는 시각 검토한 영역 좌표를 사용하며, 읽기 전용 정보와 클릭할 버튼의 의미를 설명에서 구분한다. PNG 원본에는 테두리나 번호를 합성하지 않는다. 이미지를 누르거나 키보드로 선택해 Enter를 누르면 표시 없는 원본이 새 탭에서 열린다.

2026-10-23 후속 요청에 따라 번호와 설명은 이미지 바깥으로 옮겼다. 설명의 번호 버튼을 선택하면 해당 영역의 테두리 하나만 표시하고, 표시 숨기기로 원본 상태를 확인할 수 있다. 테두리는 대상 영역 바깥에 그리며 면을 덮거나 글자를 올려놓지 않는다. 현재 선택 이름, 선택 상태와 키보드 초점을 함께 표시한다. 좁은 화면에서는 단계 들여쓰기를 줄여 이미지와 설명의 폭을 확보한다. 이는 Guide의 화면 해설에 한정한 패턴이며 제품 앱의 조작·상태·버튼을 변경하지 않는다.

이미지의 `annotations`는 원본 영역에 대한 백분율 `x/y/width/height`와 `label/description`이다. 이미지 교체 시 좌표를 다시 검토한다. `displayWidth`는 표시 최대 폭, `pixelWidth/pixelHeight`는 원본 크기로, 이미지 로딩 전에도 비율을 예약해 긴 문서의 목차 이동이 흔들리지 않게 한다. 위치 표시는 가이드 안의 해설 기능이고, 캡처 안의 제품 버튼을 실행하는 기능이 아니다.
